# Лабораторная работа № 3 — система управления учебными курсами

Учебное веб-приложение для просмотра, добавления, редактирования и удаления курсов. Реализовано на Node.js, Express.js и EJS с MVC-структурой, HTML-формами, middleware и адаптивным CSS.

**Репозиторий:** [Tcyiu/USM-NodeJS — папка lab3_egor_fomin](https://github.com/Tcyiu/USM-NodeJS/tree/master/lab3_egor_fomin)

## Запуск приложения

Необходимы установленный Node.js и npm.

```powershell
cd lab3_egor_fomin
npm install
npm start
```

Откройте <http://localhost:3000>. Для разработки с автоматическим перезапуском сервера используйте `npm run dev` (Node.js 18.11 или новее).

По умолчанию используется порт 3000; при необходимости его можно изменить переменной окружения `PORT`.

## Реализованные возможности

- просмотр списка и полной информации о курсе;
- создание, редактирование и удаление курсов;
- поиск без учёта регистра по названию курса и имени преподавателя;
- фильтрация по семестру (1–8), в том числе совместно с поиском;
- серверная валидация полей и повторное отображение введённых значений при ошибках;
- подтверждение перед удалением;
- логирование HTTP-метода, URL и времени каждого запроса;
- отдельные страницы 404 и внутренней ошибки без показа stack trace;
- адаптивное оформление списка, форм и страницы курса.

Начальный массив из пяти курсов находится в `models/courseModel.js`. Данные хранятся только в оперативной памяти: добавленные, изменённые и удалённые записи сбрасываются после перезапуска сервера.

## Структура проекта

```text
lab3_egor_fomin/
├── app.js
├── package.json
├── routes/
│   └── courseRoutes.js
├── controllers/
│   └── courseController.js
├── models/
│   └── courseModel.js
├── middleware/
│   ├── logger.js
│   └── validateCourse.js
├── views/
│   ├── courses/
│   │   ├── index.ejs
│   │   ├── details.ejs
│   │   ├── create.ejs
│   │   └── edit.ejs
│   ├── partials/
│   │   ├── header.ejs
│   │   ├── footer.ejs
│   │   └── courseForm.ejs
│   ├── 404.ejs
│   └── error.ejs
└── public/
    └── css/
        └── style.css
```

- `routes/` связывает URL и HTTP-методы с контроллерами.
- `controllers/` обрабатывает запросы и выбирает EJS-шаблон.
- `models/` хранит курсы и операции с массивом.
- `middleware/` содержит логирование и проверку формы.
- `views/` содержит страницы EJS и повторно используемые partials.
- `public/` содержит статические файлы оформления.

## Маршруты

| Метод | URL | Назначение |
|---|---|---|
| GET | `/` | Перенаправление на `/courses` |
| GET | `/courses` | Список, поиск (`?search=node`) и фильтр (`?semester=1`) |
| GET | `/courses/new` | Форма добавления |
| POST | `/courses` | Создание курса |
| GET | `/courses/:id` | Просмотр курса |
| GET | `/courses/:id/edit` | Форма редактирования |
| POST | `/courses/:id/edit` | Сохранение изменений |
| POST | `/courses/:id/delete` | Удаление курса |

Например, поиск и фильтрация одновременно: `/courses?search=ivan&semester=1`.

## Как протестировать вручную

Запустите сервер командой `npm start`, затем проверьте в браузере:

1. `/` перенаправляет на список курсов.
2. На `/courses` видны начальные курсы; попробуйте поиск `ivan`, выберите семестр или совместите оба фильтра.
3. Откройте курс, затем попробуйте редактирование и удаление.
4. Добавьте курс: он должен появиться в списке, а его ID создаётся автоматически.
5. Отправьте форму с пустым названием, неверным числом кредитов или семестром вне диапазона 1–8: отобразятся сообщения, а введённые данные сохранятся в форме.
6. Откройте `/courses/999` и неизвестный URL: должна показаться страница 404.
7. Посмотрите терминал сервера: для каждого запроса выводятся метод, URL и дата со временем.
